# Data Scientist Career Track – DataCamp Projects

This repository contains my projects, exercises, and hands-on implementations completed throughout the DataCamp Data Scientist Career Track. The program focuses on building practical data science and machine learning skills using Python and real-world datasets.

---

## Overview

Throughout this track, I worked on data preprocessing, exploratory data analysis, feature engineering, machine learning, dimensionality reduction, and natural language processing (NLP). The projects emphasize practical workflows commonly used in real-world data science pipelines.

---

## Skills & Topics Covered

### Data Preprocessing
- Handling missing and inconsistent data
- Data cleaning and transformation
- Encoding categorical variables
- Datetime conversion and feature extraction

### Feature Engineering
- Creating new features from raw datasets
- Aggregating numerical information
- Regular expression (RegEx) extraction
- Text-to-numeric transformations

### Feature Selection
- Removing redundant and highly correlated features
- Selecting relevant variables for modeling
- Reducing feature-space complexity

### Natural Language Processing (NLP)
- TF-IDF vectorization
- Text feature extraction
- Word importance analysis
- Filtering sparse text features

### Dimensionality Reduction
- Principal Component Analysis (PCA)
- Explained variance analysis
- High-dimensional feature reduction

### Machine Learning
- Naive Bayes Classification
- K-Nearest Neighbors (KNN)
- Train-test splitting and stratification
- Model evaluation using accuracy metrics

---

## Key Learnings

- Feature engineering strongly impacts model performance
- Clean and structured data improves predictive accuracy
- TF-IDF effectively transforms text into machine-readable features
- PCA reduces dimensionality while preserving important variance
- Simpler models can perform well with properly engineered features
