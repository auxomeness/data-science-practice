# Data Scientist Career Track – DataCamp Projects

This repository contains my work, exercises, and projects completed as part of the **DataCamp Data Scientist Career Track**. The focus of this track is to build practical skills in data analysis, machine learning, and feature engineering using Python.

---

## Overview

Throughout this program, I worked with real-world datasets to develop and apply key data science techniques, including data preprocessing, feature engineering, text processing, dimensionality reduction, and machine learning modeling.

---

## Key Skills Covered

### Data Preprocessing
- Handling missing and inconsistent data
- Encoding categorical variables (Label Encoding, One-Hot Encoding)
- Converting data types and extracting datetime features

### Feature Engineering
- Creating new features from raw data
- Aggregating numerical features
- Extracting information using regular expressions
- Transforming text data into numerical representations

### Feature Selection
- Removing redundant and highly correlated features
- Selecting relevant features based on data structure and relationships
- Reducing dimensionality of feature space

### Natural Language Processing (NLP)
- TF-IDF vectorization
- Text feature extraction and weighting
- Identifying important words in documents
- Filtering text-based feature spaces

### Dimensionality Reduction
- Principal Component Analysis (PCA)
- Understanding explained variance ratio
- Reducing feature space while preserving information

### Machine Learning Models
- Naive Bayes classification
- K-Nearest Neighbors (KNN)
- Train-test splitting with stratification
- Model evaluation using accuracy score

---

## Tools & Technologies

- Python
- pandas

- scikit-learn
- regex (re)

---

## Datasets Used

- Volunteer dataset (text, categorical, and datetime features)
- Hiking dataset (numerical and string-based features)
- Wine dataset (continuous numerical features)

---

## Key Learnings

- Data quality and feature engineering significantly impact model performance
- Proper feature selection reduces noise and improves efficiency
- TF-IDF is effective for converting text into meaningful numerical features
- PCA helps reduce dimensionality while preserving variance
- Simpler models can perform well with well-engineered features
